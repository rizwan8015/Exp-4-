# Exp - 4 HOSPITAL MANAGEMENT SYSTEM

# AIM:
To design and develop a Hospital Management System using UML diagrams to manage patient details, doctor details, appointments, treatments, and billing efficiently.
# SRS (Procedure):
Step 1: Problem Identification
The main problem is the need for a simple and efficient system to manage hospital activities such as patient registration, doctor management, appointment booking, treatment, and billing.

Step 2: Requirement Analysis
Identify user needs (patient, doctor, and administrator).
Define functional requirements: patient registration, login, doctor search, appointment booking, patient record management, treatment details, and billing.
Define non-functional requirements: security, reliability, accuracy, speed, and usability.

Step 3: System Design
Draw UML diagrams to represent the system:

Use Case Diagram
Activity Diagram
Class Diagram
Package Diagram
Communication Diagram
Sequence Diagram

Design the database with tables for Patient, Doctor, Appointment, Treatment, and Billing.
